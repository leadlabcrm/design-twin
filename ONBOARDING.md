# Go-Live Onboarding — everything the assistant needs to deliver a launch-ready site

Fill this once per project. Anything left blank becomes a flagged placeholder in the delivery —
**a fully filled form means the output ships with zero placeholders.** Give it to the assistant
together with the extracted template and the PROMPT.

Attach files in ONE folder (Drive link or zip) laid out exactly like this:

```
onboarding/
├── answers.md            ← this file, filled
├── logo/                 ← see §2
├── photos/               ← see §6, named as instructed
├── menu-or-catalog/      ← PDF or per-item list with prices
└── legal/                ← policies, licenses (if any)
```

## 2. Brand assets
- **Logo:** SVG or transparent PNG ≥1000px wide (NOT a PDF/JPG). Both light-on-dark and
  dark-on-light versions if you have them. Wordmark and icon-only mark separately if both exist.
- Brand colors (hex) and fonts, if defined. If not defined, say "use the template's" —
  don't guess.
- Favicon source (square, ≥512px) — or "make from logo".

## 5. Content per section (the assistant will map these to the design)
- **Menu/catalog:** the real thing with real prices (PDF or a list). Mark: 5 signature items,
  current best-seller, anything seasonal/leaving soon.
- **Reviews:** 4–6 REAL quotes, copied verbatim from Google/Zomato, with reviewer first name +
  month. Screenshots welcome. (Invented reviews are never used.)
- **Team:** names + roles + photos for anyone shown on the site. If no team section is wanted,
  say so.
- **Offers/combos:** only ones that actually run, with exact terms. "None yet" is a valid answer.
- **FAQs:** the 5–8 questions customers actually ask (parking? veg? group size? delivery radius?).
- **Blog/news:** 3+ real items (title + 2–3 paragraphs + a photo each), or say "hide blog".

## 6. Photos & video (this decides how premium the site looks)
Minimums — phone photos are fine if sharp and in good light:
- **Hero:** 3–5 options, landscape, ≥2500px wide (or 10–20s video, horizontal, steady).
- **Food/product:** 1 photo per signature item minimum, ≥1500px, shot from consistent angles.
- **Space/ambience:** 5–10 (exterior sign, dining room, any special feature — live kitchen,
  charcoal pit, private dining).
- **People:** team/chef shots if a team section is wanted; candid service shots help.
- Name files descriptively: `hero-dining-room-1.jpg`, `dish-chicken-biriyani.jpg`,
  `team-head-chef-abdul.jpg`. Note any photo that must NOT be used publicly.

### How the assistant uses this
Every fact on the site traces to a line in this form or to the template itself. The delivery
notes list any field that was blank and what placeholder covers it. If §5 Reviews and §6 Photos
are filled, the site is ready to go live without a single invented word or borrowed image.
